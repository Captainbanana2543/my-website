Experience Focus

Academic Experience in Analog & Mixed-Signal Design

Through school projects, I have gained experience with CMOS inverter operation, transistor behavior, threshold voltage extraction, and device-to-circuit relationships. I studied how process parameters such as doping, oxide thickness, and device structure affect switching behavior, noise margin, and circuit performance.

PLL / VCO Design Experience

I worked on a phase-locked loop design targeting a 6–12 GHz frequency range. The project included a phase-frequency detector, charge pump, loop filter, current-starved ring VCO, and feedback divider. I analyzed tuning range, KVCO, loop stability, phase noise, jitter, and power tradeoffs.

Sensor Interface & Mixed-Signal System Experience

I designed a sensor system using an analog-output capacitive soil moisture sensor with an ESP32 ADC. This project helped me understand sensor physics, analog signal conversion, ADC sampling, calibration, quantization, noise, and cross-sensitivity.

Projects

PLL / High-Speed Clock Generation Project

Designed and analyzed a PLL architecture for high-speed clock generation. The project included PFD, charge pump, loop filter, current-starved ring VCO, and feedback divider design. I studied tuning range, loop bandwidth, phase margin, jitter, phase noise, power, and control-voltage ripple.

Tools: Cadence Virtuoso, Spectre, MATLAB-style analysis, Analog IC Design

CMOS Device & Inverter Simulation

Simulated CMOS device behavior and inverter operation, including NMOS/PMOS transfer characteristics, threshold voltage extraction, doping effects, and voltage transfer curve analysis. This project helped connect semiconductor process behavior with circuit-level performance.

Tools: Silvaco ATHENA/ATLAS, CMOS Design, Device Simulation

Capacitive Sensor Interface System

Built a mixed-signal sensor system using a capacitive soil moisture sensor and ESP32 ADC. The project included analog voltage sensing, ADC conversion, calibration, filtering concepts, and analysis of noise and cross-sensitivity.

Tools: ESP32, ADC, Sensors, Calibration, Embedded Systems

Communication Systems Simulation

Simulated an amplitude modulation and demodulation system to study frequency-domain behavior, filtering, noise effects, and carrier synchronization. This project helped me connect signal processing theory with practical system-level simulation.

Tools: Simulink, MATLAB, Signal Processing, Communication Systems
